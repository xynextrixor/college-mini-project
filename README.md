# College Mini Project Hub

Seven different, beginner-friendly web projects. Each project is a standalone HTML file with its own CSS and JavaScript.

## Projects

| Student | Folder and file | Project |
|---|---|---|
| Rahul | `rahul/calculator.html` | Calculator |
| Sourabh | `sourabh/weather-card.html` | Weather card |
| Rohit | `rohit/notes-app.html` | Notes app |
| Kartik | `kartik/digital-clock.html` | Digital clock |
| Anmol | `anmol/todo-list.html` | To-do list |
| Satyakam | `satyakam/expense-tracker.html` | Expense tracker |
| Aakib | `aakib/quiz.html` | Quiz |
| Deepak | `deepak/unit-converter.html` | Unit converter |

## How to use

1. Open the root `index.html` in a browser.
2. Choose a student's project from the hub.
3. You can also open any project file from its folder directly.

No server, login, or installation is required.
