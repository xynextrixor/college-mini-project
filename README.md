# 🎓 Mini Project Hub (Student Portals)

A collection of 5 distinct, responsive college portal websites built with **Neobrutalism UI design** (bold borders, offset drop-shadows, retro badges, and high-contrast color palettes).

Each project has its own dedicated student directory, customized branding, individual color schemes, and owner badges while sharing the same reliable navigation flow.

## 🚀 How to Use / Run This Project

No build tools, Node.js, or complex setups are required! This is pure, standards-compliant HTML5 and CSS3.

### Method 1: Open the Main Hub
1. Open the `miniproject` folder on your computer.
2. Double-click on `index.html` to open it in your web browser (Chrome, Edge, Firefox, etc.).
3. Click on any student's card to open and preview their personalized portal.

### Method 2: Open Individual Student Portals
Navigate directly into any student's folder:
- **Rahul:** open `miniproject/rahul/login.html`
- **Sourabh:** open `miniproject/sourabh/login.html`
- **Rohit:** open `miniproject/rohit/login.html`
- **Kartik:** open `miniproject/kartik/login.html`
- **Anmol:** open `miniproject/anmol/login.html`

### 🔄 Page Flow in Each Portal:
1. **Login Page (`login.html`)**: Enter username and password, then click **Enter / Login** to access the welcome page. You can also click the link at the bottom to register.
2. **Signup Page (`signup.html`)**: Enter your name, student roll number, and password, then submit to return to the login screen.
3. **Welcome Dashboard (`welcome.html`)**: Displays "Access Granted" confirmation with a **Logout** button that safely navigates back to the login screen.

## 🛠️ Features Included
- **Valid HTML5 Standards:** Proper character encoding (`UTF-8`) and responsive viewport settings on all pages.
- **Responsive Layout:** Works on both mobile and desktop screens.
- **Neobrutalism Design:** Bold hard borders, 3D offset drop-shadows, tilted logo stickers, and fixed owner tags.
- **No external dependencies:** Fast loading and completely offline capable.
