# 🎓 College Mini Project Hub (Student Portals)

A collection of 5 distinct, responsive college portal websites built with **Neobrutalism UI design** (bold borders, offset drop-shadows, retro badges, and high-contrast color palettes).

Each student has their own folder with their own `index.html` entry point, custom branding, and unique owner badges.

## 🚀 How to Use / Run This Project

### Method 1: Open the Main Hub
1. Open the project root folder.
2. Double-click on `index.html` to open it in any browser.
3. Click any student's card to jump directly into their portal.

### Method 2: Open Any Student's Folder Directly
Because every folder contains an `index.html`, opening the folder or double-clicking `index.html` directly opens that student's login portal:
- **Rahul:** `rahul/index.html`
- **Sourabh:** `sourabh/index.html`
- **Rohit:** `rohit/index.html`
- **Kartik:** `kartik/index.html`
- **Anmol:** `anmol/index.html`

### 🔄 Navigation Flow in Each Portal:
1. **Login Page (`index.html`)**: Enter username and password, then click **Login / Enter** to access the dashboard.
2. **Signup Page (`signup.html`)**: Enter details and click submit to return to `index.html`.
3. **Welcome Page (`welcome.html`)**: Displays "Access Granted" confirmation with a **Logout** button linking back to `index.html`.
